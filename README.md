# Aryan Beltharia — Personal Portfolio

Personal portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Featured Project
- **The Shadow Bridge** — Full-stack special education marketplace platform ([theshadowbridge.com](https://www.theshadowbridge.com/))

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
git clone https://github.com/Aryan1419/PORTFOLIO.git
cd PORTFOLIO
npm install
npm run dev
```
